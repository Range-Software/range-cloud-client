## Version 1.1.0

### Improvements

- All icons are redrawn in one clean, light style shared with Range FEA: a
  24 x 24 grid, 1.5 px rounded strokes, pale tinted fills and no gradients or
  black outlines. Colours carry one meaning each - slate for neutral objects,
  blue for navigation and information, green for create, confirm and run, red
  for remove and errors, amber for edit and warnings
- Every icon has a variant for the dark colour scheme, drawn with brighter
  strokes and deep tinted fills. The variant in use follows the active palette
  and switches immediately when the colour scheme is changed
- Both sets are generated by `pixmaps/generate_icons.js`, so the light and the
  dark icons cannot drift apart
- The Windows application icon fills the whole icon area instead of following
  the macOS grid with its wide transparent margin, and the ICO file carries
  dedicated images from 16 to 256 px. The macOS icon is unchanged
