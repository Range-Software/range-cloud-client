# Logs

Open the folder with application log files. The folder is opened in the file browser of the operating system (Finder on macOS, File Explorer on Windows, the file manager on Linux).

Application folders are located in `Documents/Range Software/Cloud Client` in the user's home folder. The Mac App Store version keeps them in `~/Library/Containers/com.range-software.cloud-client/Data/Library/Application Support/Range Software/Cloud Client`, as the sandbox does not allow it to write to the Documents folder.
